# Правила работы над Workflow Lab (для Codex App)

**Сфера:** репозиторий для улучшения Workflow; рабочий код — `workflow/`. Прочитай `HOW_WE_WORK.md` и текущую итерацию `docs/ITERATION-01.md` перед изменениями.

1. Мы улучшаем Workflow **для Codex App/авторизованного Codex CLI**, без собственного OpenAI API key. Не добавляй API-зависимость, внешнюю оркестрацию или новые модели без отдельного решения.
2. Открытая папка Codex App и Git-корень должны совпадать с корнем этого репозитория. Не обращаться к оригиналу `C:\agentic_2026\workflow` и не изменять его.
3. Меняй **только согласованный этап** в отдельной ветке. До правок: цель, входные данные, ожидаемый результат и риски. После: тесты, `git diff --check`, список файлов, доказательства и отчёт.
4. Никогда не утверждай согласование за пользователя, не обходи `approval`/`pending`. При неопределённом результате Codex turn не повторяй автоматически; сначала проверка чата, состояния и файлов.
5. Не выдавай вызов `thread/start` за открытие окна Codex App. UI-навигацию можно считать успешной лишь после ответа реального UI-инструмента; иначе отметь ограничение.
6. Не запускай/не разрешай shell и запись для рабочих агентов без явно согласованного теста и реальной изоляции. Старые параметры Codex не заменяй неподтверждёнными обходами.
7. Исходные `workflow/agents/*.md` — промпты ролей движка, **не** инструкции по разработке данного репозитория. Их нельзя автоматически подмешивать в контекст разработчика.
8. Сырые журналы, токены, SQLite, локальные пути/имена и дампы Codex не коммитить. Обезличенные отчёты — в `reports/`; `reports/raw/`, `reports/private/`, `reports/incoming/` игнорируются.
9. Сохраняй минимальную документацию: при изменении функции обнови её контракт, тест, актуальную итерацию и журнал решений. Не дублируй целиком содержимое чатов в Markdown.
10. Если задача — **аудит/проектирование**, не меняй исполняемый движок без отдельного указания. Если обнаружена потребность удалить файл, сперва проверь импорты, тесты и установочный пакет.

**Приёмка:** изменение не считается готовым, пока не показаны реальные тесты/доказательства и не получено решение пользователя. Начальные 29 офлайн-тестов не доказывают совместимость с реальной установленной версией Codex.
