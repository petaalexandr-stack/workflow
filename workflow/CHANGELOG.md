# CHANGELOG

## 0.7.0 — Independent Modules

- Убраны DAG, Stage Loop, Block Runner и Block Coordinator как уровни управления.
- Добавлен детерминированный `ModuleController` с последовательными независимыми модулями.
- Сохранены два обязательных начальных согласования и приёмка каждого модуля.
- Исполнитель получает только выбранные утверждённые handoff; есть адресная доработка одной роли.
- Возможна динамическая последовательность и повторное использование шаблонов модулей.
- Обновлён Codex Skill; именованные чаты Codex Bridge сохранены.
- Сохранены System Design light/full и обязательный Documentation.
- Восстановление, устаревшие токены, хранение SQLite и контроль состояния Codex сохраняются.
- Старые v0.6 запуски не изменяются автоматически.
