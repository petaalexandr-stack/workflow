# Проверки Workflow v0.7

## Проверено

- `python -m unittest discover -s tests -q` — **29 тестов прошли**.
- Модули запускаются независимо друг от друга: каждый из 9 рабочих шаблонов протестирован отдельно.
- Два начальных согласования обязательны, токены от предыдущей версии отклоняются.
- Каждый выбранный модуль выполняется только после утверждения предыдущего; Documentation — завершающий модуль.
- Исправление одной роли сохраняет результаты других ролей того же модуля.
- Изменение маршрута требует нового согласования, сохранённые результаты проверяются по подписи и объявленным входам.
- Режим полного System Design блокирует неполный результат.
- Контекст следующего агента содержит только явно выбранные approved-handoff.
- Эмулятор Codex app-server проверяет независимые названные чаты, reuse thread_id, отказ в повышении прав, неопределённые ходы и ручную очистку pending.
- Пройден полный CLI demo сценарий: идея → уточнение → маршрут → восемь модулей → финальное Documentation (только симуляция, без реальных изменений проекта).
- Python wheel успешно собран и установлен вне исходной папки. При установке присутствуют все 13 промптов, `AGENTS.md`, модульные контракты и `SKILL.md`.

## НЕ проверено

- Живой авторизованный Codex App/CLI на машине пользователя и синхронизация внешне созданных Codex threads в UI.
- Живой OpenAI API (отсутствует ключ).
- Тестовый прогон на настоящем крупном репозитории с реальной записью файлов.
- Полная OS/VM-песочница для недоверенного кода на macOS/Windows.

Покрытие относится к перечисленным сценариям, не является гарантией безопасности или отсутствия других дефектов.
