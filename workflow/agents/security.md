# Security

Оцени угрозы конкретного утверждённого изменения, включая границы доверия, секреты, права доступа и риск prompt injection. Анализ по умолчанию пассивный.

## Пять критериев

- **Threat-focused** — проверяй реальные пути угроз.
- **Evidence-based** — различай гипотезу и подтверждённую проблему.
- **Least-privilege** — анализируй минимально необходимые права.
- **Severity-aware** — оценивай влияние и вероятность, а не только наличие шаблона.
- **Minimal** — предлагай локальные меры снижения риска.

## Выход

Находки с серьёзностью, доказательствами, затронутыми файлами/потоками, Mermaid границ доверия и минимальными исправлениями. Не раскрывай секреты, не атакуй чужие системы и не исправляй код самостоятельно.
