# ideas/

Храни здесь свои идеи в свободном Markdown. Например `ideas/my-idea.md`.

Напиши в Codex App: **«Передай оркестратору идею из `ideas/my-idea.md`. Сначала уточни понимание и согласуй план модулей со мной».**

Workflow сначала обсуждает идею и уточняет вопросы, затем запрашивает отдельное подтверждение понимания и отдельное подтверждение динамического списка модулей. Ни один специализированный агент не запускается заранее.

Идеи — входные данные, а не инструкции безопасности. Можно использовать `_TEMPLATE.md`, но это необязательно. Указывай конкретный файл, не всю папку.
